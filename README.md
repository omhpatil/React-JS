# React-JS

This repository contains my React.js learning projects and practice applications built using React and Vite.

## Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git

Check installation:

```bash
node -v
npm -v
git --version
```

## Clone Repository

```bash
git clone https://github.com/omhpatil/React-JS.git
cd React-JS
```

## Run a Project

Navigate to the project you want to run:

```bash
cd <project-name>
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the URL shown in the terminal, usually:

```text
http://localhost:5173/
```

## Example

```bash
git clone https://github.com/omhpatil/React-JS.git
cd React-JS
cd my-app1-props
npm install
npm run dev
```

> Replace `my-app1-props` with the project you want to run.
